Guia Essencial: JavaScript Fundamentos

Este guia expandido cobre os conceitos fundamentais do JavaScript, focado em estruturas de controle de fluxo e manipulação avançada de arrays. Ideal para consultas rápidas e estudos estruturados.

1. Estruturas de Controle (Lógica)

As estruturas de controle permitem que o código tome decisões e repita ações com base em condições dinâmicas.

Condicionais

if / else / else if: A base da tomada de decisão. Avalia uma condição booleana.

if (idade >= 18) { console.log("Maior de idade"); } else if (idade === 17) { console.log("Quase lá!"); } else { console.log("Menor de idade"); }

Operador Ternário: Uma forma concisa de escrever um if/else para atribuições.

const status = (nota >= 7) ? "Aprovado" : "Reprovado";

switch: Útil para comparar o valor de uma única variável contra múltiplos casos específicos.

switch (sinal) { case 'verde': acelerar(); break; case 'amarelo': atencao(); break; case 'vermelho': parar(); break; default: console.log("Sinal quebrado"); }

Laços de Repetição (Loops)

for: Ideal quando se sabe o número exato de repetições. Composto por inicialização, condição e incremento.

for (let i = 0; i < 5; i++) { console.log(`Iteração ${i}`); }

while e do...while: Repete enquanto a condição for verdadeira. O do...while garante pelo menos uma execução.

let contador = 0; while (contador < 3) { contador++; // Executa enquanto < 3 } let tentativas = 0; do { tentativas++; // Executa primeiro, depois verifica } while (tentativas < 0);

for...of e for...in: for...of itera sobre os *valores* de objetos iteráveis (como Arrays). for...in itera sobre as *chaves/propriedades* de um objeto.

const frutas = ['Maçã', 'Banana', 'Uva']; for (let fruta of frutas) { console.log(fruta); // Imprime os nomes } const pessoa = { nome: 'João', idade: 30 }; for (let chave in pessoa) { console.log(`${chave}: ${pessoa[chave]}`); // nome: João, idade: 30 }

2. Métodos de Busca e Validação em Arrays

Estes métodos não alteram o array original, apenas procuram informações dentro dele.

indexOf(item) e lastIndexOf(item): Retornam o índice da primeira e última ocorrência, respectivamente. Retornam -1 se não encontrar.

const numeros = [10, 20, 30, 20, 50]; numeros.indexOf(20); // Retorna 1 numeros.lastIndexOf(20); // Retorna 3

includes(item): Retorna true se o item existir, caso contrário false. Mais legível que usar indexOf() !== -1.

const temTrinta = [10, 20, 30].includes(30); // Retorna true

find(callback) e findIndex(callback): Excelentes para buscar objetos complexos. Retornam o primeiro *elemento* ou seu *índice* que passe na condição.

const usuarios = [{id: 1, nome: 'Ana'}, {id: 2, nome: 'Carlos'}]; const user = usuarios.find(u => u.id === 2); // Retorna {id: 2, nome: 'Carlos'}

some(callback) e every(callback): some verifica se *pelo menos um* elemento passa no teste. every verifica se *todos* passam.

const idades = [15, 18, 20]; const algumMaior = idades.some(idade => idade >= 18); // true const todosMaiores = idades.every(idade => idade >= 18); // false

3. Métodos Transformadores (Funcionais)

Base da programação funcional em JS. Eles criam e retornam um novo array (ou valor), preservando o original (imutabilidade).

map(callback): Cria um novo array transformando cada elemento. O array resultante tem sempre o mesmo tamanho do original.

const precos = [10, 20]; const comDesconto = precos.map(preco => preco * 0.9); // [9, 18]

filter(callback): Cria um novo array apenas com elementos que retornam true no teste. O tamanho pode ser menor que o original.

const numeros = [1, 2, 3, 4, 5]; const pares = numeros.filter(n => n % 2 === 0); // [2, 4]

reduce(callback, valorInicial): Reduz o array a um único valor (pode ser um número, string, objeto, etc). O acc (acumulador) guarda o estado entre as iterações.

const carrinho = [10.5, 20.0, 5.5]; const total = carrinho.reduce((acc, valor) => acc + valor, 0); // 36.0
Dica Pro: Você pode encadear esses métodos! Ex: array.filter(...).map(...).reduce(...)

4. Manipulação de Arrays

Aqui dividimos entre métodos que mutam (alteram) o array original e os que retornam novas cópias.

Mutáveis (Alteram o array original)

push(item) e pop(): Adiciona ou remove itens no final do array.

unshift(item) e shift(): Adiciona ou remove itens no início do array (reindexando os demais).

const fila = ['B', 'C']; fila.push('D'); // ['B', 'C', 'D'] fila.unshift('A'); // ['A', 'B', 'C', 'D'] fila.pop(); // Retira 'D' -> ['A', 'B', 'C'] fila.shift(); // Retira 'A' -> ['B', 'C']

splice(inicio, qtdRemover, ...itensAdicionar): Um canivete suíço. Remove, substitui ou adiciona elementos em qualquer posição.

const meses = ['Jan', 'Mar', 'Abr']; meses.splice(1, 0, 'Fev'); // Adiciona 'Fev' no índice 1. Fica: ['Jan', 'Fev', 'Mar', 'Abr']

sort(callback): Ordena os itens. Atenção: por padrão ordena como strings (ordem alfabética). Para números, passe uma função de comparação.

const numeros = [10, 5, 20, 2]; numeros.sort((a, b) => a - b); // [2, 5, 10, 20] (Ordem Crescente)

Imutáveis (Retornam um novo array/string)

slice(inicio, fim): Retorna uma cópia de uma parte do array. Não altera o original.

const pedaco = ['a', 'b', 'c', 'd'].slice(1, 3); // ['b', 'c'] (Índice 3 não incluso)

concat(outroArray): Junta dois ou mais arrays em um novo.

const todos = [1, 2].concat([3, 4]); // [1, 2, 3, 4]

join(separador): Une todos os elementos do array em uma única String, divididos pelo separador.

const url = ['www', 'google', 'com'].join('.'); // "www.google.com"
